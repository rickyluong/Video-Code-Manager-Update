# Project notes for Claude

Public download repo for the Video Code Manager browser add-on (.xpi files + updates.json).
The add-on's source and all real work live in the main VCM repo, not here.

## How to reply

- Keep replies short and visual: tables, status icons (🟢 🟡 🔴 ⚪), diagrams, checklists.
- Short labels and one-line notes. No paragraphs unless asked.
- Lead with the answer or the action needed.
- Choices = clickable cards with buttons (AskUserQuestion tool), never a typed list. Recommended option first.

## Coding hold

All coding is held until the owner types **start coding**.
Until then: plan, research and propose changes as a short visual plan, then ask with a card whose first button is "Start coding (Recommended)".
Pressing that button or typing **start coding** unlocks; **stop coding** holds it again.
